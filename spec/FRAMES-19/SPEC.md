# FRAMES-19: The resolved document

Status: accepted

## Summary

The resolved document, frames' own lockfile: what resolve has already done, its shape, and the rules for reading it.

## Motivation

An edit opened on another machine, or on the same machine a month later, should come out the same. In an NLE it often does not: a font is missing or a different version and titles reflow, a pack or a LUT has changed, a tracker run again lands a little elsewhere, a template's defaults moved. What can differ between machines and over time (installed fonts and packs, what a provider recognised or followed, theme and preset values, template arguments) must be fixed once, or a result cannot be made again. Writing every such decision out as values, with every file the roles still open pinned by hash, makes the resolved document enough to make the result again, and gives evaluation one input with nothing left to look up.

## Rules

The resolved document is frames' own lockfile: what `resolve` writes, and what evaluation and `render` read. It is not an exchange format, and frames reads only what resolve wrote. It is JSON with `"kind": "sequence"`, the one document kind ([FRAMES-6](../FRAMES-6/SPEC.md)), and `"resolved"` set to the version of the frames that wrote it ([FRAMES-18](../FRAMES-18/SPEC.md)).

What resolve has already done:

- **Keys are checked.** A resolved document carries only the keys below.
- **No text areas.** Every area is `[x, y, w, h]` and every point `[x, y]`, the padding of a text form already added ([FRAMES-2](../FRAMES-2/SPEC.md)), except a clip area, whose value changes with the clip it names: it stays `{clip, padding}`, its `padding` a theme length with the length scale applied ([FRAMES-2](../FRAMES-2/SPEC.md)), and a point of one stays `{area, point}`. Resolve has checked that its id names a clip it may name, one with the same parent or its own parent, and that no cycle holds. Each stays in the coordinate space of the clip that wrote it ([FRAMES-10](../FRAMES-10/SPEC.md)): a crop in the media pixels of its media, a parented clip's `position`, geometry and masks in the space its parent gives, and an unparented clip's in output pixels.
- **Files are pinned.** Every file a role opens (media, mattes, LUTs, fonts) is written as its absolute path and its SHA-256. An image sequence is pinned as its ordered list of files, each with its SHA-256, so a frame added, removed or changed is refused. `render` checks every hash before any role starts and refuses a file whose hash differs.
- **Decisions are written down.** Conformed crops, the measured size of a content-fit frame ([FRAMES-6](../FRAMES-6/SPEC.md)), parents, track mattes and tracks are values, not rules to apply again. A track is the target's quadrilateral on each frame followed and the similarity motion fitted to it ([FRAMES-12](../FRAMES-12/SPEC.md)).
- **Parents are named.** A clip's `parent` is the `id` of its parent clip in the same document, or `null`. Resolve has checked it: it names a clip with a picture in the same document, and no parent chain holds a cycle ([FRAMES-10](../FRAMES-10/SPEC.md)).
- **Anchor points are applied.** A clip with a box of its own (a title, a media clip, a storyline picture, a rect or ellipse placed by `width` and `height`) writes `size`, its box in output pixels (a shape's box as written, without its `outset`), `anchor`, the point its scale and rotation act around in the box's own pixels (origin at the box's top left), and `position`, where that point goes in the clip's coordinate space. A clip placed by `placement` is written with the `position` its placement gives. A storyline picture's box is the one [FRAMES-9](../FRAMES-9/SPEC.md) gives (the frame, or under content fit its crop's pixel size), which its conformed crop fills. A shape placed by `area` or `points` and an adjustment have no box: their `size` is `null`, and their `anchor` is `null` unless the clip names one, so their scale and rotation act around the centre of their geometry's box at each time ([FRAMES-1](../FRAMES-1/SPEC.md)). A shape that names an anchor writes it as the point it names of its geometry's box, or, where its `area` or `points` hold a clip area, whose box changes with the clip it names, as the placement name, and evaluation takes that point of the geometry's box at each time. `position` is `null` unless the clip writes one, and then it is where the anchor point goes.
- **Clips are named.** Every clip keeps its place in the document and its `id`, so `evaluate` and `locate` can name what made each thing drawn.
- **No names.** Theme colours, text styles, shape styles, presets and template arguments are written out as values, and so are the theme colours a preset names (a cover or a bloom `color`) in the theme where the preset is chosen. A preset is written with its arguments applied ([FRAMES-14](../FRAMES-14/SPEC.md)): it holds plain values, and no `params` and no `{"param"}` remain. Theme lengths are already multiplied by their length scale ([FRAMES-1](../FRAMES-1/SPEC.md)). Colours are `color(srgb r g b / a)`, the encoded working value at full precision ([FRAMES-26](../FRAMES-26/SPEC.md)).
- **Text is shaped.** Every title carries its box size (at the static tracking, line height and background padding), its text box `[x, y, w, h]` in that box at the same values, its `width` (the width it wraps at, `null` for a title without one), its background (`null`, or a timed `{color, padding, radius}`), its `align`, its `lineHeight` (a keyframe list), its `lines`, its runs in order and its `units`. `lines` is `null`, or, for a title whose tracking or line height takes keyframes ([FRAMES-5](../FRAMES-5/SPEC.md)), its lines in order, each `{width, baseline, clusters}` with `width` the line's width at the static tracking, `baseline` the y of its baseline in the title's box at the static line height, and `clusters` its grapheme clusters in order as `[run, first, count]` glyph ranges, a cluster set inside the glyph of the one before it a range of count 0, and the spaces that hang past the line's end in none of its clusters, so they stay where they were set. `units` is `null`, or, for a title animated by unit ([FRAMES-14](../FRAMES-14/SPEC.md)), its units in reading order, each `{box, glyphBox, glyphs, parts}` with `box` the unit's box and `glyphBox` its glyph box ([FRAMES-5](../FRAMES-5/SPEC.md)), each `[x, y, w, h]` in the title's box, `glyphs` the unit's glyphs as `[run, first, count]` ranges of run index, first glyph index and glyph count, and `parts` the parts of highlight and underline pieces it carries as `[run, piece, x0, x1]`: run index, the piece's index among the run's pieces, and the part's span across the line in the title's box ([FRAMES-5](../FRAMES-5/SPEC.md)), a run's highlight piece and its underline piece at one index sharing the part, and the first part of a piece starting at the piece's own start and the last ending at its own end, which evaluation reaches past to the piece's ends as drawn, its padding included. A run carries `source`, the index of the title's run it is set from (a title's run set over several lines or in several faces is several runs, and a piece's glyphs are the glyphs of its line's runs of that `source`), its font file, face, hash, size, its colour as a keyframe list, its stroke (`null`, or a timed `{width, color}`), its `baselineShift` as a keyframe list, its `tracking` (`null`, or a keyframe list of the tracking added after each of its grapheme clusters beyond its static tracking, in output pixels), its highlight (`{color, padding, radius, rects}` or `null`) and underline (`{color, width, offset, rects}` or `null`), each leaf there but `rects` a keyframe list, and `rects` the run's pieces in line order in the title's box: a highlight piece as `[x, y, w, h]`, from the run's ascent to its descent without padding, and an underline piece as `[x, y, w]`, from x and w long on the baseline at y ([FRAMES-5](../FRAMES-5/SPEC.md)). Its glyph ids and positions are in the title's box with kerning, features, the static tracking and the static line height applied and the baseline shift not, so evaluation raises the glyphs and the pieces by `baselineShift` at each instant, moves them by `tracking` along their lines, and moves them with their lines by `lineHeight`. A title written as a string is one run in the clip's style, and a run's character attributes come from its own style with the title's `character`, its static value with the structure its keyframes give, merged over it, and its keyframes timing the leaves of the merged value ([FRAMES-11](../FRAMES-11/SPEC.md)).
- **Masks and mattes are geometry and ids.** A clip's `mask` is `null` or a timed list of masks in order, each `{geometry, feather, invert, mode}` with the numbers of its geometry and its `feather` keyframe lists: `geometry` in one of the forms of the display list ([FRAMES-20](../FRAMES-20/SPEC.md)) in the clip's own coordinate space (the media pixels of its media for a picture, the space its geometry is in for any other clip), a path mask a closed `polyline`, and `feather` in output pixels. Each number a keyframe moves on its own is its own keyframe list: a rect's or an ellipse's `rect` and a rect's `radius`, each point of a path's `points`, and for a rect or an ellipse given by `width`, `height` and `position`, those three in place of `rect` (`{"rect": {"width": [...], "height": [...], "position": [...], "radius": [...]}}`), since keyframes time each of them apart ([FRAMES-4](../FRAMES-4/SPEC.md)). A clip's `trackMatte` is `null` or `{clip, mode, invert}`, `clip` the `id` of the matte clip. The matte clip keeps its own entry, and evaluation draws it only as a matte.
- **One clock.** Every instant on a sequence is sequence time, and keyframes keep their eases, a spring as `{"spring": {"bounce": b}}` with `b` a number ([FRAMES-4](../FRAMES-4/SPEC.md)). A clip's `in` and `out` stay on its clip time and its `speed` as written ([FRAMES-8](../FRAMES-8/SPEC.md)). A clip with `timeRemap` carries it as a keyframe list in sequence time whose values are media seconds, and its `speed` is 1. A clip without one has `timeRemap` `null`, and its clip time is its media time.
- **Lanes kept.** Clips keep document order and carry their signed `lane`, so evaluation stacks them by [FRAMES-9](../FRAMES-9/SPEC.md). A storyline transition keeps its `over`, which evaluation applies at each time.

How it is written, so the same plan gives the same bytes:

- **One layout.** It is UTF-8 JSON indented by two spaces, one member or element to a line, except that a list of numbers, strings, booleans or `null` stays on one line, and it ends with a line break. Keys come in one fixed order for each kind of object, `kind` and `"resolved"` first, never sorted.
- **One number form.** A number is the shortest decimal that reads back to the same 64-bit floating point value, with no exponent, no fraction when it is whole (`1080`, not `1080.0`), and `0` for negative zero. A string escapes `"`, `\` and control characters only, and writes every other character as itself.
- **Hashes.** A SHA-256 is 64 lower case hexadecimal digits under `sha256`, next to the absolute `file` it pins. An image sequence is `imageSequence`, its frame files in order, each `{file, sha256}`.
- **Timed values.** A timed leaf ([FRAMES-4](../FRAMES-4/SPEC.md)) is a keyframe list, a list of `{at, value, ease}` in time order, where `ease` shapes the span that starts at its keyframe, and a keyframable value is a **timed value**: its structure with each timed leaf in it a keyframe list and each static leaf its value. So `opacity` and `position` are keyframe lists, a stroke is `{width, color, join, cap, ...}` with its `width` and `color` keyframe lists and its `join` and `cap` names, and a filter is a list of entries `{ops, mix}`, each the ops of one entry of the choice (its preset's, or the one op written in place) with every op parameter that is a number or a colour a keyframe list, a parameter a preset argument fills taking that argument's keyframes, a list parameter whose elements arguments fill (`levels` `input` and `output`) a list of one keyframe list for each element, so each element keeps the keyframes and eases of its argument, and its `mix` a keyframe list. A leaf written without keyframes is one keyframe at the instant its areas take effect, and one not written is its plain value there, the layers below merged, `null` leaves written as the merged value and theme colours and `true` written out. A `scale` value is `[sx, sy]`, a number written as `[s, s]`. A keyframable value that is off (a `fill` or `stroke` of `false`, a `shadow` or `border` of `false`, no filter) is `null`.
- **Every key written.** An entry carries every key of its kind, `null` where it has none. Only the outermost document carries `"resolved"`, and a nested one is the same shape without it. Track frames are frames of media, so they keep media time, as `frames` does. An audio clip is drawn by nothing, so it is an audio entry only, a clip written with `"picture": false` included ([FRAMES-13](../FRAMES-13/SPEC.md)).

- The example is laid out to be read and keeps only the keys it explains. Hashes in the example are cut short. A glyph is `[glyph id, x, y]`, its origin in the title's box, and the example's glyph lists are cut short too.
- `format.size` is the frame size, the measured one for a content-fit frame ([FRAMES-6](../FRAMES-6/SPEC.md)). `format.duration` is the sequence end, above 0. `format.colorSpace` and `format.compositing` are the sequence's, their defaults written out ([FRAMES-26](../FRAMES-26/SPEC.md)).
- A video or image sequence keeps its frame timestamps in `frames` (cut short in the example).
- A storyline entry has `id`, `media`, `colorSpace` (the clip's `colorSpace`, or `null` where it writes none and the file's tags apply, [FRAMES-26](../FRAMES-26/SPEC.md)), `toneMap` (the clip's `toneMap`, its default `true` written out, and `null` where the media is a compound clip or a template instance, which takes none), `in`, `out`, `speed`, `timeRemap`, `start`, `end`, its box (`size`, `anchor`, `position`), its keyframable properties (`crop` as conformed crops, `position`, `scale`, `rotation`, `opacity`, `radius`, `border` as `{width, color}`, `shadow` as `{radius, offset, color}`, and `filter` as a list of entries `{ops, mix}`) as timed values in sequence time, its `blend`, `mask`, `trackMatte` and `track`, and `transition` as `null` or `{start, end, over, incoming, outgoing, cover, matte}` with spans and files inline. The curve of its sound crossfade is written only on the audio entries it crossfades. A cover or matte that shows media carries it pinned, a video with its `frames`, and its `duration` in media seconds (0 for a still), so evaluation shows media time p × `duration` at progress p ([FRAMES-14](../FRAMES-14/SPEC.md)) without opening the file.
- A solid storyline entry carries its colour as `solid`, a keyframe list of colours, and `media` is `null`.
- A clips entry is a title, a shape, an adjustment or a media clip with its visible window `start` and `end` already narrowed by [FRAMES-8](../FRAMES-8/SPEC.md) and [FRAMES-12](../FRAMES-12/SPEC.md), its keyframable properties as timed values in sequence time, its animation as `{entrance, loop, exit, by, stagger}` with its spans inline and `by` and `stagger` `null` unless a title's choice plays by unit (its default `stagger` then written), its `blend`, `lane`, `storyline` (the index of the storyline entry it is connected to, or `null` for a sequence clip), `parent`, `mask`, `trackMatte` and `track`.
- A media clip also carries `conform`, `colorSpace` and `toneMap`, as a storyline entry does, and as timed values or `null` its `radius`, `border` (`{width, color}`), `shadow` (`{radius, offset, color}`) and `filter` (a list of entries `{ops, mix}`), and its `crop` as every crop conformed to its box by `conform`, the whole picture when none is written. A timed media clip also carries `in`, `origin`, `out`, `speed`, `loop` and `timeRemap`: it plays from clip time `in` at sequence time `origin`, the start of its window, which lies before `start` where tracking narrowed it. A connected or sequence media clip with `timeRemap` writes `in`, `out` and `loop` as `null`, since its keys give the media time at every instant of its window ([FRAMES-8](../FRAMES-8/SPEC.md)), and its `timeRemap` keys are in sequence time like its other keyframes.
- A shape entry carries `shape` (`rect`, `ellipse` or `path`) and its geometry, each a timed value or `null`: `area` for a rect or ellipse placed by its area, `width` and `height` for one placed by its box, `points` and `closed` for a path, and `outset` for a rect or ellipse, `null` for a path. Its geometry is as the clip wrote it and its `outset` is a theme length with the length scale applied: evaluation grows the outline it draws by it on every side in the shape's own coordinates, as a carried length ([FRAMES-20](../FRAMES-20/SPEC.md)), so it keeps its size under a parent's zoom and stretches with a per-axis scale, and its box stays as written ([FRAMES-11](../FRAMES-11/SPEC.md)). A shape placed by its geometry writes its `position` and its `anchor` where a box would, its `anchor` as a point: the point it names of its geometry's box at its instant ([FRAMES-1](../FRAMES-1/SPEC.md)), or `null` for the centre of that box at each time. It carries `radius` and `trim` as keyframe lists, and `fill` (a colour or a gradient), `stroke` (`{color, gradient, width, join, cap, start, end, dash, dashOffset}`, one of `color` and `gradient` `null`, `dash` `null` for a whole stroke) and `shadow` (`{radius, offset, color}`) as timed values or `null`, its shape style applied and its lengths in output pixels ([FRAMES-11](../FRAMES-11/SPEC.md)). A gradient keeps its points and radius as fractions of the shape's box and its stops' colours as `color(srgb r g b / a)`.
- An adjustment entry carries `adjust`, its filter as a timed list of entries `{ops, mix}`, and its `mask`, which is where it applies.
- A clip's or a storyline entry's `track` is `null` or `{media, time, target, frames}`: the pinned media it follows (its own, or its parent's), the target's quadrilateral as found on the frame at media time `time`, before padding, and every frame followed as `{time, quad, motion}` in media time. A quadrilateral is four points `[[x, y], [x, y], [x, y], [x, y]]` in media pixels, top left, top right, bottom right and bottom left as the target faces on the frame it was found. `motion` is the similarity fitted from the target to that frame's quadrilateral ([FRAMES-12](../FRAMES-12/SPEC.md)), as an affine matrix `[a, b, c, d, tx, ty]` in media pixels, in the form of the display list's `transform` ([FRAMES-20](../FRAMES-20/SPEC.md)). A `motion` that is not a similarity, `[a, b, -b, a, tx, ty]` with a scale above 0, stops reading, naming its place. So does a `media` that is not the media its clip follows: its own for a storyline entry and for a media clip of video or image sequence, and its parent's for any other clip ([FRAMES-12](../FRAMES-12/SPEC.md)).
- An audio entry is a source of sound, storyline clips included, with its `volume` and `pan` keyframes in sequence time, its fades, its transitions, and its `audioFilter` as `null` or a timed list of entries `{ops, mix}` in sequence time, presets and arguments applied, every default parameter written ([FRAMES-13](../FRAMES-13/SPEC.md)). Evaluation multiplies them into the mix plan. Its `incoming` and `outgoing` are `null` or `{start, end, audio}`: the range of the transition it crossfades over and the curve its preset's `audio` names ([FRAMES-14](../FRAMES-14/SPEC.md)). It plays from clip time `in` at sequence time `origin`. A storyline clip's audio entry runs over its drawn range with its edges moved by its `split`, and a connected clip's over its visible window with its edges moved by its `split`, its `start` and `end` written so, and its `incoming` and `outgoing` are moved with the edge they cross, as [FRAMES-13](../FRAMES-13/SPEC.md) places them. A clip with `timeRemap` plays no sound, so it has no audio entry ([FRAMES-8](../FRAMES-8/SPEC.md)).
- A compound clip or a sequence template instance carries its nested resolved sequence in place of a media file. Its `size`, `background`, `conform` and `compositing` apply ([FRAMES-3](../FRAMES-3/SPEC.md)).

### Reading a resolved document

- Resolve is deterministic for the same document, arguments, media, theme, presets, packs, fonts, recognised text and tracks.
- Evaluating and rendering a resolved document needs its pinned files and nothing else. It names no role: the command that renders it picks them ([FRAMES-21](../FRAMES-21/SPEC.md)), and the same result is promised for the same ones.
- A frames reads a resolved document written by a frames of its own major version at its minor version or an earlier one, and refuses any other, naming both versions. Made again by the version that wrote it, a resolved document gives the same result. A later version gives the same result too, except where a patch brought evaluation or a role back to this specification.
- Display lists and the mix plan have a JSON form too, with `"displayList"` and `"mixPlan"` set to the version of the frames that wrote them, so what evaluation gives a role can be checked, recorded and replayed apart from it. They are read by the same rule as a resolved document.
- Evaluation and `render` trust a resolved document as they trust resolve. They check its version, and `render` its hashes, not its rules again. Evaluation opens no file.

## Interactions

Its version is [FRAMES-18](../FRAMES-18/SPEC.md). Evaluation reads it ([FRAMES-20](../FRAMES-20/SPEC.md)). Every document-taking command takes it ([FRAMES-23](../FRAMES-23/SPEC.md)). The values it fixes come from [FRAMES-2](../FRAMES-2/SPEC.md) (areas and points), [FRAMES-6](../FRAMES-6/SPEC.md) (content fit), [FRAMES-8](../FRAMES-8/SPEC.md) (time and `timeRemap`), [FRAMES-10](../FRAMES-10/SPEC.md) (parents), [FRAMES-11](../FRAMES-11/SPEC.md) (shapes, runs, masks and track mattes), [FRAMES-12](../FRAMES-12/SPEC.md) (tracks), [FRAMES-14](../FRAMES-14/SPEC.md) (preset arguments) and [FRAMES-26](../FRAMES-26/SPEC.md) (colours and colour spaces).

## Alternatives considered

An exchange format (FCPXML, OpenTimelineIO, an EDL): those carry an edit between tools and leave out what frames must fix to make a result again, such as shaped glyphs, recognised text, fitted tracks and pinned hashes. frames reads only what resolve wrote, so its form can follow frames.

A project file that keeps names and is resolved again on every render, as an NLE project relinks media and lays out titles with the fonts it finds: the result would change with the machine's fonts, packs, providers and theme, and the principle of a result reproducible from one file would not hold.

Writing only the tracker's quadrilaterals and fitting the motion in evaluation: the fit is a decision like any other, and writing it leaves evaluation with arithmetic only.
